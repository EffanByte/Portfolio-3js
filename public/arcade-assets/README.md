# Arcade menu assets

Icons are unmodified 24px SVGs from [Pixelarticons](https://github.com/halfmage/pixelarticons), by Gerrit Halfmann, licensed under MIT. See `pixelarticons-LICENSE.txt`.

The locally served [Pixelify Sans](https://github.com/google/fonts/tree/main/ofl/pixelifysans) variable font is licensed under the SIL Open Font License 1.1. See `PixelifySans-LICENSE.txt`.

The page uses CSS masks to tint the library icons and renders them at multiples of their native 24px size.
